# 同梱エージェントへ担当を渡す

独立した作業単位を分担する場合に使う。スキルを読むだけの仕事や、小規模な同一担当の作業を必ず委譲する必要はない。

| 担当 | 渡す仕事 | 必ず渡すスキル |
| --- | --- | --- |
| `devlow-worker` | 調査・設計・実装・検証のうち、終了条件と所有範囲が定まった単位 | このスキルの `SKILL.md` と必要な工程資料 |
| `comment-curator` | 指定範囲のコメント分類、必要な知識のOKF保存と照合、コメント削除 | [no-comments](../../no-comments/SKILL.md) |

利用環境のエージェント一覧から同梱担当を選ぶ。製品が名前にプラグインの接頭辞を付ける場合は、表示された識別名を使う。利用できなければ、許可された汎用担当へ同じスキルと担当条件を渡すか、親が処理して委譲未実施と示す。モデル・ツール・権限は利用環境の設定に従い、担当定義のためだけに権限を広げない。

起動前に、参照するスキルと工程資料を実際の配置場所から絶対パスへ解決し、読み取れることを確かめる。プロジェクトの作業ディレクトリをプラグインへ移さない。

担当には目的、終了条件、基準と対象の版、編集可否、所有するファイル・記録、既存設計・承認・証拠、前提と報告先、解決したスキルパスを渡す。関連作業を継続する担当がいれば再利用する。同じファイルやOKF文書を並行して編集させず、他担当の変更を戻さないことを明示する。

親は返された結果を実際の差分・証拠と照合して受け入れる。作成者と同じ担当を独立レビューとして数えず、必要な独立レビューは [interrogate](../../interrogate/SKILL.md)の手順で別に扱う。担当の完了報告だけで全体を完了にしない。
