# 直前の説明をかみ砕く

直前の自分の回答、またはユーザーが指定した説明を言い直す。何が言いたかったのかを最初に一文で示し、理解に必要な理由や例を続ける。

- 普段使う言葉を選ぶ。避けられない専門語は、その場で短く説明する。
- 全体を短くしても、結論を左右する条件、例外、不確実さは残す。
- 比喩より具体的な動作を示す。例を足す場合は、実際に確認した事実と混同させない。
- 対象の名前や参照先が必要なら保持する。新しい主張や未依頼の作業を足さない。

言い換えた回答を直接返す。元の回答が見えない場合は説明したふりをせず、対象の文章を確認する。事実誤認に気づいた場合は、単なる言い換えとせず訂正したことを短く示す。
