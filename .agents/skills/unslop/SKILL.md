# 意味を保って文章を整える

対象と求める文体を確認し、依頼された文章を編集する。チャット内の文章なら修正文を返す。ファイルの修正は依頼された範囲に限り、レビューなら指摘または修正案を返す。執筆者がAIかどうかを判定する作業ではない。

次の順で読み直す。

1. **内容を固定する。** 事実、数値、条件、否定、確度、引用、根拠リンクを特定する。必要な留保や警告を冗長と決めつけない。
2. **曖昧さを減らす。** 「柔軟な基盤」「大幅に改善」のような表現は、既に示されている動作や数値へ置き換える。裏付けがなければ事実を足さず、曖昧さが残ると示す。出典不明の主張を強い断定に変えない。
3. **余分な表現を省く。** 内容を伴わない前置き・繰り返し・賞賛・結び、不要な対比、同じ対象への言い換えを減らす。理由なく三項にそろえたり、全行へ強調ラベルを付けたりしない。
4. **読める文へ戻す。** 長く複雑な文は分け、省略しすぎた断片には主語・動詞・つながりを補う。業務で定着した用語を不正確な平易語へ置き換えない。
5. **意味を照合する。** 元の文章と比較し、結論、適用範囲、禁止、例外、確実さが変わっていないことを確認する。

句読点、箇条書き、見出し、敬語は読みやすさに応じて使う。特定の語や記号を一律に禁止せず、日本語・英語それぞれの文脈と文書の規約を尊重する。コード、識別子、URL、正確さが必要な引用・法的文言は保持する。

依頼に応じて修正文または差分を返す。説明は意味に影響する変更や、解消できなかった曖昧さに絞る。推敲だけでは解決しない事実確認や構成変更は、必要な作業として分ける。
